QUANTUM INSPECTOR — COSMIC NEBULA IMPLEMENTATION REVIEW
13 October 2026 (America/Los_Angeles)

Open: Tools > Quantum Inspector > Open > Clustered Graph.
Leave Lock selection off to follow Project assets, folders and Hierarchy GameObjects,
including while Investigation Lock is enabled. Direct external component selections
still require Investigation Lock to be off.
Graph Mode no longer enables Investigation Lock on entry. Its initial personal
preference is unlocked; an explicitly chosen lock is remembered.

IMPLEMENTED
UI Toolkit, Unity 6000.3.7f1, existing Editor-only assembly and actual graph model.
Cosmic Nebula tokens; cached seeded cloud/star field; measured family contours;
owner instrument arcs and distinct silhouette; opaque gradient node surfaces;
typed paths, selection rings, OFF/MISSING/PIN labels; bounded selected-path accent.
No layout engine, scene effect, scene transform or player dependency was added.

Hierarchy selection changes owner/context. Component selection selects the exact
component under its owner. Project selection changes folder context and reveals
the selected file after discovery. Internal graph selection preserves the root.
An identity-only poll catches selection notifications deferred by the Editor.

Full / Reduced / Off and Low / Balanced / Cinematic are independent choices.
Personal graph appearance/motion/lock/ambient choices use EditorPrefs overrides,
not serialized shared-preset values. Shared color tokens remain explicitly editable.
Expansion 320 ms; collapse/ordinary transitions 240 ms; focus 340 ms; hover 110 ms;
selection 180 ms. A single 520 ms selection-path accent means user feedback,
not runtime execution, events or traffic. No perpetual edge particles.
Ambient is opt-in, background-only, +/-4 horizontal / +/-3 vertical logical pixels
over 32/38 seconds; locked ambient requires its separate opt-in. Reduced/Off stop it.

Previews have fixed reserved bounds and bounded retries. Persistent prefab owners
and assets can show actual previews; scene owners use an honestly labelled type
icon. Calling Unity's scene-owner asset-preview renderer caused a measured 1.56 s
stall during review; that path was removed and guarded by a regression assertion.
